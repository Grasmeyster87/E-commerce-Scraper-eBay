# eBay Product Page Scraper & Tag Parser (Тестовий стенд)

Автономний міні-додаток для скрапінгу конкретної сторінки товару eBay та відладки алгоритмів витягування даних по тегам і дереву DOM.

Додаток повністю ізольований від основного бекенду та може бути перенесений у будь-яку іншу папку чи репозиторій.

---

## 📁 Структура проекту

- **`launch_chrome.bat`** — скрипт запуску Google Chrome з прапорцем віддаленої відладки (`--remote-debugging-port=9222`) та збереженням профілю користувача в локальній папці `browser_profile/`.
- **`scraper.js`** — модуль керування браузером (підключення до порту 9222, авто-запуск Chrome якщо він вимкнений, навігація на сторінку товару, скрол, збереження HTML зліпка сторінки).
- **`parser.js`** — модуль парсингу конкретної сторінки товару (назва, ціна, стан, доставка, продавець, таблиця характеристик `itemSpecifics`, фотографії та всі посилання з галереї медіа), а також інструменти інспекції ієрархії тегів.
- **`index.js`** — точка входу: запускає скрапінг, передає сторінку в парсер та форматовано виводить усі дані і структуру тегів у консоль. Характеристики товару виводяться у двох колонках без рамок таблиці.
- **`package.json`** — незалежний маніфест залежностей проекту.
- **`debug/`** — папка, куди автоматично зберігаються зліпки HTML (`latest_product.html`) для ручного аналізу тегів.
- **`browser_profile/`** — локальна папка кешу та сесії Chrome.

---

## 🚀 Як запускати

### Варіант 1. Запуск за замовчуванням (тестовий товар):
```bash
node index.js
```
*(Chrome запуститься автоматично на порті 9222 з локальним профілем `browser_profile`)*

### Варіант 2. Запуск для конкретного посилання на товар:
```bash
node index.js https://www.ebay.com/itm/123456789012
```

### Варіант 3. Ручний запуск Chrome перед стартом (якщо потрібно):
1. Запустіть файл `launch_chrome.bat` (подвійним кліком або в терміналі).
2. Запустіть скрипт:
   ```bash
   node index.js
   ```

## 🔬 Як працювати з алгоритмами парсингу тегів у `parser.js`

У файлі `parser.js` доступні два режими:
1. **Витягування готових полів** у методі `ProductParser.parseProduct(page)`:
   - Тут ви можете додавати та тестувати селектори для будь-яких специфічних елементів сторінки товару.
2. **Інструменти дослідження тегів**:
   - `ProductParser.inspectTagHierarchy(page, selector, maxDepth)` — показує повне дерево вкладеності тегів, класів та тексту для будь-якого блоку.
   - `ProductParser.findTagsByText(page, text)` — знаходить в яких саме тегах на сторінці міститься потрібне слово або число (корисно для пошуку неочевидних селекторів).

## 📦 Як перенести цю папку в окреме місце

1. Скопіюйте папку `test` у будь-яке нове місце на диску.
2. Відкрийте термінал у новій папці та встановіть залежності:
   ```bash
   npm install
   ```
3. Все готово! Запускайте `node index.js`.
